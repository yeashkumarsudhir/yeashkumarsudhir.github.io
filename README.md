## Overview

This repository hosts my personal developer portfolio on GitHub Pages. It presents my technical background, academic credentials, resume access, and a detailed technical case study of **Advocate Diary** (a cloud-backed legal practice management web application).

## Technologies Used

- **HTML5:** Semantic document structure, accessibility attributes, and Open Graph metadata.
- **CSS3:** Custom Swiss-Editorial grid layout, CSS custom properties (variables), and media queries.
- **Vanilla JavaScript (ES6+):** Tabbed technical blueprint switcher, clipboard email copy utility, and `IntersectionObserver` scroll indicators.
- **Typography:** Google Fonts (`Instrument Serif`, `Plus Jakarta Sans`, and `JetBrains Mono`).
- **Hosting:** GitHub Pages.

## Repository Structure

- `index.html` — Single-file application containing the complete markup, styling, inline SVG brand icons, and interactive scripts.
- `profile.jpeg` — Profile portrait image displayed in the hero section.
- `resume.pdf` — Downloadable PDF version of my internship resume.
- `README.md` — Repository documentation.
