01 / The Problem

Paper Registers & Missed Dates

Practicing advocates rely on physical legal registers and paper diaries that are slow to search inside courtrooms, vulnerable to loss, and make tracking daily cause-lists across multiple court halls error-prone.

02 / What I Built

Modular JS + Cloud Firestore

Designed and deployed a tailored web platform with modular script loading (dashboard.js, clients.js, theme.js), structured NoSQL collections (clients, cases, recycleBin), and Firebase Auth.

03 / The Impact

Real-Time Courtroom Access

Reduces physical record dependency with real-time cloud synchronization, fast page loads without heavy framework overhead, and a two-step Recycle Bin recovery pipeline to help prevent accidental data loss.

advocate-diary-co.web.app
■ Centralized Case & Client Management

Instant onboarding of clients with case numbers, court hall assignments, judge details, and active legal stages.

■ Daily Cause-List & Dashboard

Dynamic dashboard displaying active litigations, today's court hearings, and upcoming schedules at a single glance.

■ Cloud Persistence with Firestore

Cloud-based data storage helps keep critical hearing updates accessible across mobile and desktop sessions, subject to proper security, synchronization, and backup configuration.

■ Recycle Bin & Safe Recovery

Built-in two-step deletion pipeline allowing advocates to restore accidentally deleted case files effortlessly.

Layer 01 · Client Engine
Modular Vanilla ES6+
  • dashboard.js (Cause-list metrics & alerts)

  • Firebase Auth (Practitioner sessions)
  • Cloud Firestore (Real-time NoSQL sync)
  • Document-based queries by clientId & hearing date
  • Two-step soft-delete to recycleBin

Deployment & Security
  • Hosted on Firebase CDN edge servers

  • Git & GitHub version control workflow
